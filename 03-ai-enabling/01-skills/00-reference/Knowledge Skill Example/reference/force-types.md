# Force Types Catalog

Detailed catalog of force types with examples across different contexts.

## Push Forces (Toward Change)

Forces that create dissatisfaction with the current state.

| Subcategory | Description | Business Example | Relationship Example |
|-------------|-------------|-----------------|---------------------|
| Pain | Active suffering from current state | "We're losing deals to competitors" | "Every meeting feels unproductive" |
| Cost | Financial or resource pressure | "Maintenance costs up 30% year-over-year" | "We're spending too much time on reports" |
| Risk | Growing danger of staying put | "Our tech debt will cause outages" | "If we don't address this, they'll churn" |
| External pressure | Market or regulatory force | "GDPR requires us to change by Q2" | "Their board is demanding results" |
| Opportunity cost | What's being missed | "We can't pursue AI without modern infra" | "Our competitors offer this already" |

## Pull Forces (Toward Change)

Forces that make the new state attractive.

| Subcategory | Description | Business Example | Relationship Example |
|-------------|-------------|-----------------|---------------------|
| Vision | Inspiring picture of the future | "Imagine real-time customer insights" | "We could become their strategic partner" |
| Capability | New ability unlocked | "AI-powered recommendations" | "Deeper relationship understanding" |
| Social proof | Others succeeding | "Three competitors already switched" | "Other clients love this approach" |
| Quick win | Immediate visible benefit | "30% faster onboarding in week one" | "First meeting using forces framework was revelatory" |
| Status | Improved position | "Being seen as innovation leaders" | "Trusted advisor, not vendor" |

## Anxiety Forces (Against Change)

Forces that create fear about the new state.

| Subcategory | Description | Business Example | Relationship Example |
|-------------|-------------|-----------------|---------------------|
| Migration risk | Fear of transition failure | "What if we lose data?" | "What if the new approach confuses them?" |
| Learning curve | Fear of incompetence | "My team can barely use the current tool" | "I don't know how to have that conversation" |
| Unknown unknowns | Fear of surprises | "What problems will we discover?" | "What if it surfaces something uncomfortable?" |
| Commitment fear | Fear of irreversibility | "What if it doesn't work and we can't go back?" | "What if this changes the relationship dynamic?" |
| Cost anxiety | Fear of overspending | "What if it costs more than projected?" | "What if this takes too much time?" |

## Habit Forces (Against Change)

Forces that create comfort with the current state.

| Subcategory | Description | Business Example | Relationship Example |
|-------------|-------------|-----------------|---------------------|
| Familiarity | Known workflows | "We know how this system works" | "Our meeting format works fine" |
| Sunk cost | Investment in current | "We spent 2 years building integrations" | "We've built this rapport over time" |
| Muscle memory | Automatic behaviors | "My team runs reports in their sleep" | "I always open with the same question" |
| Network effects | Others depend on current | "Three departments use our current setup" | "Their whole team expects this format" |
| Good enough | Current meets minimum bar | "It works, even if it's not perfect" | "They're not unhappy, just not excited" |

## Force Interaction Patterns

Forces don't exist in isolation. Common interaction patterns:

| Pattern | Description | Example |
|---------|-------------|---------|
| **Amplifying** | Two forces reinforce each other | High push (cost) + strong pull (savings) = momentum |
| **Canceling** | Opposing forces neutralize | Strong pull + equal anxiety = stalemate |
| **Cascading** | One force triggers another | Resolving top anxiety reveals a hidden push force |
| **Seasonal** | Forces vary by timing | Budget anxiety peaks in Q4; opportunity pull peaks in Q1 |
| **Asymmetric** | One side dominates | Multiple weak pushes can't overcome one intense habit |
