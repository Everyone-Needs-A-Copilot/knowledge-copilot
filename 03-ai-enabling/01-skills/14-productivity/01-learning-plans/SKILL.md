# Learning Plans

Self-directed learning is one of the most powerful things available to anyone with curiosity and an internet connection. But "I want to learn about X" without a plan usually ends one of two ways: you buy a course, watch three videos, and never finish. Or you read seventeen articles, feel vaguely informed, and could not explain what you learned to anyone.

The difference between consuming content and actually learning is structure. A good learning plan does what a good curriculum does: it sequences knowledge from foundational to advanced, balances input (reading, watching) with output (practicing, teaching), and builds in checkpoints so you know whether the learning is actually sticking. You are building your own personal syllabus -- and you get to be both the student and the professor.

## Framework

### Learning Plan Design Methodology

| Phase | Action | Output |
|-------|--------|--------|
| **1. Define the goal** | What specifically do you want to be able to do or understand? | Clear, measurable learning objective |
| **2. Assess current level** | What do you already know? Where are the gaps? | Honest self-assessment (beginner / intermediate / advanced) |
| **3. Curate resources** | Find the best books, courses, people, and communities | Prioritized resource list (5-10 items, not 50) |
| **4. Structure the path** | Sequence resources from foundational to advanced | Week-by-week or phase-by-phase plan |
| **5. Practice and apply** | Build in exercises, projects, or real-world application | Applied learning activities |
| **6. Review and adjust** | Check comprehension, adjust pace, fill gaps | Regular self-assessment |

### The "T-Shaped" Learning Approach

Go broad first to build context, then go deep in the areas that matter most.

```
       BROAD (survey the landscape)
  ______|______|______|______|______
                |
                |  DEEP (master what matters)
                |
                |
                |
```

| Phase | Approach | Duration |
|-------|----------|----------|
| **Survey** | Read 2-3 overview sources (introductory book, survey article, podcast episode) | 1-2 weeks |
| **Map** | Identify subtopics and dependencies. What do you need to know first? | 1-2 days |
| **Select** | Choose 2-3 areas to go deep on (you can not master everything) | 1 day |
| **Deep dive** | Focused study on selected areas with practice and application | 2-8 weeks per area |
| **Connect** | Link what you have learned back to the broader landscape and other knowledge | Ongoing |

### Resource Curation Framework

Not all learning resources are created equal. Evaluate before committing.

| Resource Type | Best For | Watch Out For |
|--------------|----------|--------------|
| **Books** | Deep understanding, foundational knowledge, author's complete thinking | Can be outdated, dense, time-consuming |
| **Online courses** | Structured progression, visual learning, guided practice | Completion rates are abysmal (under 10%), quality varies wildly |
| **Podcasts** | Exposure to ideas, hearing practitioners think out loud, passive learning | Easy to consume without retaining, not deep enough alone |
| **YouTube/Video** | Visual demonstrations, tutorials, seeing techniques | Rabbit holes, inconsistent quality, hard to reference later |
| **Mentors/Coaches** | Personalized feedback, accountability, real-world context | Finding the right one, cost, availability |
| **Communities** | Peer learning, motivation, diverse perspectives | Can be echo chambers, time-consuming, varying quality |
| **Practice/Projects** | Applying knowledge, discovering gaps, building portfolio | Need enough foundation first, can be frustrating without guidance |
| **Articles/Blogs** | Current information, specific topics, quick answers | Shallow, SEO-driven, not always trustworthy |

### Resource Quality Evaluation

| Signal | Good Resource | Poor Resource |
|--------|-------------|--------------|
| **Author credibility** | Practitioner with real experience, respected in the field | Anonymous, no credentials, self-proclaimed guru |
| **Specificity** | Teaches concrete skills and frameworks you can apply | Vague inspiration without actionable takeaways |
| **Recommendations** | Recommended by multiple trusted sources | Only promoted by the creator themselves |
| **Structure** | Clear progression from simple to complex | Jumps around, no logical sequence |
| **Recency** | Current or timeless | Outdated information in a fast-moving field |
| **Reviews** | Specific praise about what people learned | Generic praise or no reviews |

## Define Done

- [ ] System or plan addresses the specific life area
- [ ] Steps are concrete and actionable, not aspirational
- [ ] Time and resource requirements estimated realistically
- [ ] Progress tracking mechanism defined

## Application

### Learning Sprint Design (4-Week Focused Learning)

A learning sprint is a time-boxed period of focused study on one topic. Four weeks is long enough to go meaningfully deep and short enough to maintain motivation.

| Week | Focus | Activities |
|------|-------|-----------|
| **Week 1: Foundation** | Build the base understanding | Read introductory book or take first module of course. Take notes. Map the key concepts. |
| **Week 2: Deepen** | Go deeper on core concepts | Continue primary resource. Start practice exercises. Watch supplementary videos. |
| **Week 3: Apply** | Put knowledge to use | Start a mini-project or real-world application. Join a community discussion. Teach someone what you have learned so far. |
| **Week 4: Synthesize** | Connect and consolidate | Complete primary resource. Write a summary of what you learned. Identify gaps for future study. Decide: continue or move on? |

### Daily Learning Rhythm

| Time Block | Activity | Duration |
|------------|---------|----------|
| **Morning** (high focus) | Active study: reading, course work, challenging material | 30-60 min |
| **Commute/Transition** | Passive input: podcasts, audiobooks | 15-30 min |
| **Evening** (lower energy) | Light review: notes, flashcards, community reading | 15-20 min |

**Total daily investment: 60-90 minutes.** Consistency beats intensity. 30 focused minutes every day outperforms a 5-hour Saturday marathon.

### Building a Personal Curriculum

For a major learning goal, design a multi-phase curriculum:

```
## [Topic] Learning Curriculum

### Goal
[What I want to be able to do/understand by the end]

### Current Level
[Beginner / Some exposure / Intermediate / Advanced in specific areas]

### Phase 1: Foundations
- Primary resource: [Book/Course title]
- Supplementary: [Podcast/Videos]
- Practice: [Exercise or mini-project]
- Duration: [X weeks]
- Milestone: [What I should be able to do/explain after this phase]

### Phase 2: Core Skills
- Primary resource: [Book/Course title]
- Supplementary: [Community/Mentor/Videos]
- Practice: [Larger project or applied work]
- Duration: [X weeks]
- Milestone: [What I should be able to do/explain after this phase]

### Phase 3: Advanced / Specialization
- Primary resource: [Advanced book/course]
- Supplementary: [Research papers/Expert content]
- Practice: [Real-world project or portfolio piece]
- Duration: [X weeks]
- Milestone: [What I should be able to do/explain after this phase]

### Ongoing
- Communities to participate in: [List]
- People to follow: [List]
- Review schedule: [How often to revisit and reinforce]
```

### Learning Goal Templates

| Domain | Good Goal | Too Vague |
|--------|-----------|-----------|
| Language | "Hold a 10-minute conversation in Spanish about everyday topics" | "Learn Spanish" |
| Technical | "Build and deploy a personal website using React" | "Learn web development" |
| Creative | "Complete 10 watercolor paintings using wet-on-wet technique" | "Learn to paint" |
| Professional | "Lead a strategic planning session using OKR methodology" | "Get better at management" |
| Financial | "Understand and implement a three-fund portfolio" | "Learn about investing" |
| Physical | "Complete a 5K run without stopping" | "Get in shape" |

### When to Quit vs. Push Through

| Signal | Quit | Push Through |
|--------|------|-------------|
| Consistently dreading study time | The topic is genuinely not for you | Normal resistance to hard learning |
| No progress after sustained effort | Wrong approach or resource, not wrong topic | You are in the "valley of despair" (this is normal) |
| Goal has changed | Your original reason no longer applies | The goal still matters, motivation is temporarily low |
| Opportunity cost is too high | Something more important needs your attention | You are just distracted by novelty |
| You have learned enough for your purpose | 80% knowledge serves your actual need | Deep mastery is the goal |

## Quick Reference

### Before Starting Any Learning Plan

- [ ] Goal is specific and measurable (not "learn about X")
- [ ] Current level honestly assessed
- [ ] Primary resource selected (start with one, not five)
- [ ] Daily time commitment realistic (30-60 min)
- [ ] Duration defined (4-week sprint or multi-phase curriculum)
- [ ] First practice/application activity identified
- [ ] Calendar blocked for study time

### Weekly Learning Check-In

- [ ] Did I study consistently this week? (4+ days out of 7)
- [ ] Can I explain what I learned to someone else?
- [ ] Did I practice or apply anything (not just consume)?
- [ ] Am I on pace with my plan?
- [ ] Do I need to adjust the plan (too fast, too slow, wrong resource)?

### The Learning Stack

| Layer | What It Means | How to Build It |
|-------|--------------|----------------|
| **Consume** | Take in new information | Read, watch, listen |
| **Process** | Make sense of it | Take notes, summarize, map concepts |
| **Practice** | Try doing it | Exercises, projects, real-world application |
| **Teach** | Explain it to others | Write about it, discuss in community, mentor someone |
| **Connect** | Link to existing knowledge | How does this relate to what I already know? |

Each layer increases retention. Consuming alone retains roughly 10%. Teaching retains roughly 90%.

## Anti-Patterns

| Anti-Pattern | Why It Fails | Better Approach |
|--------------|-------------|-----------------|
| Collecting resources without starting | 47 bookmarks and 12 saved courses is not learning | Pick one resource and start today |
| Passive consumption only | Watching and reading without practice is entertainment, not learning | Build in practice from week one |
| No defined goal | Wandering through content with no destination | Define what "done" or "good enough" looks like |
| Perfectionist sequencing | "I need to read all the prerequisites first" | Start with the best beginner resource and fill gaps as you go |
| Course hopping | Starting 5 courses and finishing none | Commit to one primary resource per learning sprint |
| Learning in isolation | No feedback, no accountability, no community | Find at least one person to discuss your learning with |
| All input, no output | Never writing, building, or teaching | The "explain it to a friend" test: if you can not, you have not learned it |
| Ignoring the plateau | Quitting when progress feels slow | Plateaus are where deep learning happens. Adjust approach, do not quit. |


## Quality Tests

### Practicality Test
- Plan fits within actual available time and resources
- **PASS:** Total time commitment estimated and fits available schedule
- **FAIL:** Plan assumes unlimited time or resources

### Completeness Test
- Plan covers the full scope of the task or system
- **PASS:** All steps from start to finish are enumerated
- **FAIL:** Key steps missing or assumed to be obvious
