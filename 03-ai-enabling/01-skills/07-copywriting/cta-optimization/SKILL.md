# CTA Optimization Skill

Write calls-to-action that motivate users to take the next step. Effective CTAs are clear about what happens, create urgency without manipulation, and align with user intent.

---

## Core Principles

### The CTA Mindset

| Principle | Description | Example |
|-----------|-------------|---------|
| Clarity | User knows exactly what happens | "Download PDF" not "Click here" |
| Value | Focus on benefit to user | "Start free trial" not "Sign up" |
| Specificity | Concrete outcome named | "Get my report" not "Submit" |
| Low friction | Minimize perceived effort | "Create free account" not "Register now" |
| Relevance | Matches user's current intent | "Compare plans" on pricing page |

### CTA Psychology

| Factor | Application |
|--------|-------------|
| Loss aversion | "Don't miss out" (use sparingly) |
| Social proof | "Join 10,000+ users" |
| Commitment consistency | "Continue my progress" |
| Reciprocity | "Get your free guide" |
| Authority | "See expert recommendations" |

---


## Define Done

- [ ] Copy serves the user's goal at this specific touchpoint
- [ ] Tone matches the brand voice and emotional context
- [ ] Copy is concise — no unnecessary words
- [ ] Accessible language (no jargon unless audience expects it)

## CTA Formulas

### Primary CTA Formulas

| Formula | Pattern | Example |
|---------|---------|---------|
| Verb + Noun | [Action] [Object] | "Download guide" |
| Verb + My/Your | [Action] [possessive] [Object] | "Start my trial" |
| Get + Benefit | Get [desired outcome] | "Get instant access" |
| Verb + Timeframe | [Action] + [Time benefit] | "Start in 60 seconds" |

### Secondary CTA Formulas

| Formula | Pattern | Example |
|---------|---------|---------|
| Learn + Topic | Learn [more about X] | "Learn how it works" |
| See + Object | See [proof/details] | "See customer stories" |
| Compare + Options | Compare [choices] | "Compare plans" |
| Question | [Relevant question] | "Have questions?" |

## CTA by Context

### Landing Pages

| Position | Purpose | CTA Style |
|----------|---------|-----------|
| Hero | Primary conversion | High-commitment: "Start free trial" |
| Mid-page | Reinforce after context | Benefit-focused: "Get started free" |
| Bottom | Catch committed readers | Action-specific: "Create my account" |
| Exit intent | Reduce bounce | Lower-ask: "Get the checklist" |

### Email Campaigns

| Email Type | CTA Focus | Example |
|------------|-----------|---------|
| Newsletter | Engagement | "Read the full story" |
| Product launch | Exploration | "See what's new" |
| Promotional | Conversion | "Claim your discount" |
| Re-engagement | Return | "Pick up where you left off" |
| Transactional | Action | "View your receipt" |

### In-App Prompts

| Context | CTA Style | Example |
|---------|-----------|---------|
| Feature announcement | Try action | "Try [feature]" |
| Upgrade prompt | Value-focused | "Unlock unlimited [thing]" |
| Feedback request | Low friction | "Share feedback (1 min)" |
| Onboarding | Next step | "Continue setup" |

## Button Copy Patterns

### Action Verbs by Intent

| User Intent | Strong Verbs |
|-------------|--------------|
| Learning | Discover, Explore, Learn, See |
| Acquiring | Get, Download, Access, Claim |
| Starting | Start, Begin, Create, Try |
| Continuing | Continue, Resume, Next |
| Committing | Join, Subscribe, Upgrade, Buy |
| Confirming | Confirm, Save, Update, Apply |

### First Person vs Second Person

| Approach | When to Use | Example |
|----------|-------------|---------|
| First person ("my") | Personal decisions, accounts | "Start my free trial" |
| Second person ("your") | Help content, service-focused | "Get your report" |
| Neutral | Universal actions | "Download now" |

### Word Count Guidelines

| CTA Type | Ideal Length | Example |
|----------|--------------|---------|
| Primary button | 2-4 words | "Get started free" |
| Text link | 3-6 words | "See how it works" |
| Email button | 2-5 words | "Claim your spot" |

## Conversion-Focused Techniques

### Reducing Friction

| Friction | Fix | Example |
|----------|-----|---------|
| Cost uncertainty | Add "free" | "Start free trial" |
| Time uncertainty | Add timeframe | "Set up in 2 minutes" |
| Commitment fear | Add "no obligation" | "Try free, cancel anytime" |
| Complexity fear | Simplify action | "One-click signup" |

### Creating Urgency (Use Honestly)

| Type | Pattern | Example |
|------|---------|---------|
| Time-limited | "[Action] before [deadline]" | "Register by Friday" |
| Quantity-limited | "[X] spots remaining" | "3 spots left" |
| Exclusive access | "Get early access" | "Join the waitlist" |

### Social Proof in CTAs

```
"Join 50,000+ professionals"
"Start your free trial (rated 4.9 stars)"
"Get started like 10,000+ teams"
```

## Primary + Secondary CTA Pairs

### Pairing Strategy

| Primary CTA | Secondary CTA | Use Case |
|-------------|---------------|----------|
| "Start free trial" | "See pricing" | SaaS landing page |
| "Buy now" | "Add to wishlist" | E-commerce |
| "Schedule demo" | "Watch video" | Enterprise sales |
| "Download app" | "Learn more" | Mobile product |
| "Subscribe" | "See sample issue" | Newsletter |

### Visual Hierarchy

```
[===================]  ← Primary: High contrast, larger
[ Start free trial  ]

  Learn more →          ← Secondary: Text link, subtler
```

## A/B Testing Insights

### What to Test

| Element | Variables |
|---------|-----------|
| Action verb | "Get" vs "Download" vs "Access" |
| Possessive | "Start trial" vs "Start my trial" |
| Specificity | "Sign up" vs "Create free account" |
| Urgency | With deadline vs without |
| Length | Short vs detailed |

### Common Winning Patterns

| Test | Often Wins | Why |
|------|------------|-----|
| Generic vs specific | Specific | Clarity reduces uncertainty |
| Submit vs action verb | Action verb | Describes outcome |
| Learn more vs See [X] | See [X] | More concrete |
| Free vs no modifier | With "free" | Reduces risk perception |

## Anti-Patterns to Avoid

### Weak CTAs

| Avoid | Why | Use Instead |
|-------|-----|-------------|
| "Click here" | Vague, inaccessible | Specific action |
| "Submit" | Generic, unclear | Named action |
| "Learn more" everywhere | Overused, weak | Specific content |
| "Go" | Too brief | Describe destination |

### Manipulative Patterns

| Avoid | Why |
|-------|-----|
| Fake urgency | Erodes trust |
| Confirmshaming | "No, I don't want to save money" |
| Hidden costs | High refund/churn |
| Dark patterns | Unethical, often illegal |

### Common Mistakes

| Mistake | Fix |
|---------|-----|
| Too many CTAs | One primary per section |
| Competing CTAs | Clear visual hierarchy |
| CTA doesn't match headline | Align promise and action |
| Generic across pages | Contextualize to page content |

## CTA Accessibility

### Requirements

| Rule | Implementation |
|------|----------------|
| Descriptive text | "Download annual report" not "Download" |
| Sufficient contrast | 4.5:1 minimum ratio |
| Large click target | Min 44x44 pixels |
| Focus visible | Clear keyboard focus state |

### Screen Reader Considerations

```
Bad:  "Click here to download"
Good: "Download the 2024 annual report (PDF, 2.4 MB)"
```

## Testing Checklist

Before launching CTAs:

| Check | Question |
|-------|----------|
| Clarity | Is the outcome obvious? |
| Value | Is the benefit clear? |
| Accessibility | Works for screen readers? |
| Urgency | Honest, not manipulative? |
| Alignment | Matches page content? |
| Hierarchy | Primary/secondary clear? |
| Mobile | Tappable, readable? |

## Quality Tests

### Clarity Test
- A first-time user understands the copy without context
- **PASS:** Copy uses plain language and active voice
- **FAIL:** Copy requires domain knowledge or re-reading to understand

### Action Test
- User knows exactly what to do after reading the copy
- **PASS:** Clear call-to-action or next step is obvious
- **FAIL:** Copy describes a situation but doesn't guide the user forward
