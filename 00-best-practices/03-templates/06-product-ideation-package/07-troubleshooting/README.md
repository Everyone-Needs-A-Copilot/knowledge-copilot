# Troubleshooting Guide

> **Status:** STUB — filled post-launch.
>
> This document covers common operational issues, diagnostic steps,
> and resolution procedures for {{PRODUCT_NAME}}.

---

## When this gets filled

This guide is populated from real incidents. Entries should be added whenever a
non-obvious problem is diagnosed and resolved — not before. Pre-writing hypothetical
troubleshooting steps is low-value; documenting real ones is high-value.

After launch, every incident that takes more than 15 minutes to diagnose should
produce a troubleshooting entry here.

## What this will cover

- Common startup failures and their causes
- Authentication / session issues
- External API integration failures (what breaks, how to detect it, how to recover)
- Database connection problems
- Build and deployment failures
- Performance degradation: how to identify the source
- Error message reference: what each non-obvious error means and what to do

---

*Do not pre-fill with hypothetical scenarios. Document real issues as they occur.*
