## Glossary

| Term | Definition |
|------|-----------|
| MLP | Minimum Lovable Product. The smallest version of the product that delivers a genuinely good experience — not just the minimum that works. |
| CDO | Chief Design Officer. The role responsible for experience intent and design approval within the factory model. |
| CTO | Chief Technology Officer. The role responsible for implementation decisions within the factory model. |
| Gate | A milestone checkpoint in the factory process. Work does not proceed past a gate until its criteria are met and approved. |
| JTBD | Jobs to Be Done. A framework for understanding what users are trying to accomplish, expressed as: "When [situation], I want to [motivation], so I can [outcome]." |
| CV | Critical View. A view (screen or interaction) identified as high-stakes for the user experience — one that must be prototyped and approved before development. |
| ADR | Architecture Decision Record. A short document capturing a significant technical decision, its context, and its consequences. |
| DoD | Definition of Done. The checklist that must be fully verified before any piece of work is considered complete. |
| WCAG AA | Web Content Accessibility Guidelines Level AA. The accessibility standard that {{PRODUCT_NAME}} targets as a minimum. |
| SAST | Static Application Security Testing. Automated analysis of source code for security vulnerabilities before runtime. |
| PII | Personally Identifiable Information. Any data that can be used to identify an individual. Triggers enhanced security and privacy obligations. |
| MTM | Moments That Matter. The critical points in the user journey where the experience succeeds or fails — the design focus of the product. |

*Add terms as they are introduced in the documentation. Prefer plain language definitions over jargon-heavy ones.*
