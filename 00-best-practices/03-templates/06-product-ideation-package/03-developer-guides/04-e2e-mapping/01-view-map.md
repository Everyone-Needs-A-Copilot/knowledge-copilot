## View Dependencies

Which views can only be reached from a specific other view, and which are global entry points.

```
Authentication (future)
└── [Primary Dashboard]       ← Primary entry point after login
    │
    ├── [Empty State]         ← If no items exist
    │
    └── [Core Workflow View]
        │
        └── [Editor]          ← Requires item in active state
            │
            └── [Review]      ← From Editor (review action)

Settings                      ← Global navigation; not journey-dependent
├── Settings — [Category 1]
└── Settings — [Category 2]

Prototype Hub (/prototypes)   ← Presentation only; not in production navigation
├── CV-01 overview
│   ├── Concept A
│   └── Concept B
└── [Additional CVs per brief]
```

### Entry Points

Views accessible without navigating from another view first:

| View | How accessed |
|------|-------------|
| [Primary Dashboard] | Global navigation; default route after login |
| Settings (any sub-view) | Global navigation; accessible at all times |
| Prototype Hub | Direct URL `/prototypes` — presentation context only |

### Dead Ends

Views the user cannot leave without resolving a condition:

| View | Blocking condition | Resolution |
|------|-------------------|------------|
| [Empty State] | No items configured | User must take the setup action |
| Error states | System failure | User must retry or take the fallback action |
