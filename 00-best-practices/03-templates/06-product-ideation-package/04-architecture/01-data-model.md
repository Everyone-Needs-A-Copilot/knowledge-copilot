- **`ConversationMessage.contextSnapshot`**: [Keep as a JSON blob (`jsonb` in Postgres) rather than relational columns as context evolves.]

### Phase 2 / 3 Additions

- **`[CollaborationEntity]`** (if multi-user collaboration is added): will introduce comments, assignments, and review threads.
- **`[NotificationPreference]`**: per-user settings for alerts.
- **`[SubmissionRecord]`**: a formal record of the submission event.

### Migration Conventions

- All schema changes must have a named migration file.
- Additive changes (new nullable columns, new tables) are non-breaking and can deploy without downtime.
- Renaming or removing columns requires a two-phase migration: add new, migrate data, remove old — never rename in place.
