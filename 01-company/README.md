# 01-company — the company layer

Your organization's knowledge: identity, brand, voice, services, go-to-market, methods.
This is the **company/org layer** — shared, not personal (personal knowledge lives in your
personal tier; see [`../templates/personal-layer.md`](../templates/personal-layer.md)).

Run [`/knowledge-setup`](../.claude/commands/knowledge-setup.md) to have the wizard propose a
structure sized to you (enterprise / SMB / solo) and create the sections. Or add them by
hand following [`../templates/company-profiles.md`](../templates/company-profiles.md).

**Rule:** no secrets here — ever. Reference them as `requires_secret: <NAME>`.
